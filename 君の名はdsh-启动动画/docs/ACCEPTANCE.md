# 安装验收（1.2.0）

自动检查见 test-results.json 和 component-test-results.json。以下真实 DSH 检查尚待用户安装验证。

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 路径 | 查看两个安装目录 | 每个目录直接有 package.json、lib/index.js、lib/client.js |
| 元数据 | 设置 → 插件 | 分别出现“君の名はdsh · 启动动画”和“君の名はdsh · 界面主题” |
| 只开主题 | 关闭动画后重新打开 DSH | 直接进入主题；无视频、无拦截点击 |
| 只开动画 | 关闭主题，使用宿主原界面 | 有视频和原音效；结束仍为宿主原界面，无本主题背景或配色 |
| 同时开启 | 打开两个独立开关 | 尾声约1.2秒渐隐进入本主题 |
| 分别停用 | 播放中关闭主题/动画 | 任意一个关闭不移除或重启另一个 |
| 浅色宿主 | 打开文件卡片、代码/编辑摘要、删除工作区弹窗、菜单 | 深蓝卡片配清楚的浅色文字；浅色按钮深字；删除与新增等语义色保持不同 |
| 深色宿主 | 重复上述页面 | 同样清楚，没有浅底浅字 |
| 停用还原 | 关闭界面主题 | 恢复宿主配色，包括原有浅色弹窗；不改宿主模式偏好 |
| 音效 | 完整观看、点击声音控件 | 原音轨保留；策略拒绝时可主动开启，不重播或跳过 |
| 鼠标/触摸 | 在背后新会话或发送按钮位置跳过，按住后再松开 | 当前手势不穿透，新手势正常 |
| 键盘/减弱动态 | Esc/Enter/空格；系统减少动态 | 跳过有效，不将按键输入聊天框；减少动态短淡出 |
| 异常恢复 | 无效视频/背景地址 | 相关组件有界降级，另一组件不被阻塞 |
| 原视觉 | 查看Logo、侧栏折叠按钮、结绳与湖景 | Logo可读、按钮保持原定位、结绳不裁切、原湖景与彗星保留 |
| 重启升级 | 覆盖旧主题、添加动画并重启 | 无旧1.1.9混合条目继续播放两次的现象 |
| 清理 | 分别反复启停 | 无残留视频/遮罩、重复结绳或失效按钮 |

如某个版本的第三方控件仍有硬编码白底，请记录其语义属性或所属 style[data-plugin-css] 模块导出，添加到 src/config.js 的 surface 映射后重建。不要把所有 div 的背景设成透明。
