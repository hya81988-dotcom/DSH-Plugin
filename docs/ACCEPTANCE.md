## 若发现区域未适配

在浏览器开发者工具定位该区域，记录其稳定属性或所属 `style[data-plugin-css]` 模块及导出类名，仅修改 `src/config.js` 对应配置并重新 build。不要通过 `body * { background: transparent !important }` 之类的全局规则解决，否则会破坏浮层、代码块和文字对比度。
